# Paper explainers

Interactive, plain-language explainers for the four papers closest to FlipRate. Open a file in a browser; each is a single self-contained HTML page (fonts load from Google Fonts).

| Paper | File | Why it matters for FlipRate |
| --- | --- | --- |
| SycEval (Fanous et al., 2025, [arXiv 2502.08177](https://arxiv.org/abs/2502.08177)) | [syceval.html](syceval.html) | Closest prior work; cited on the sprint page. Rebuttal ladder, progressive vs regressive sycophancy. |
| FlipFlop, "Are You Sure?" (Laban et al., 2023, [arXiv 2311.08596](https://arxiv.org/abs/2311.08596)) | [flipflop.html](flipflop.html) | One-turn version of Experiment 1a. |
| ELEPHANT (Cheng et al., 2025, [arXiv 2505.13995](https://arxiv.org/abs/2505.13995)) | [elephant.html](elephant.html) | Social sycophancy; cited on the sprint page. The both-sides test maps onto multi-speaker ordering. |
| MASK (Ren et al., 2025, [arXiv 2503.03750](https://arxiv.org/abs/2503.03750)) | [mask.html](mask.html) | Separates belief from pressured statement. |

Each page has: a short story version, the questions the paper asked, the setup step by step, key results, limits, how it maps onto the FlipRate arms, and a short quiz.

Numbers are taken from the arXiv PDFs. Example chats marked "illustrative" were written for the pages. Points marked as our reading (for example the missing re-ask control in SycEval and FlipFlop) are our interpretation, not claims from the papers.
